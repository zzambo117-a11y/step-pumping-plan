## 1. 관측정 용도 (2026-11-03 데스크톱 반영, 최우선)

### 데스크톱 규칙
`app.py` → `render_basic_info()`

1. **용도** 선택: `양수 / 관측 / 관정 / 기타`. 기본값 `양수`.
2. 용도 = `관측`일 때만 두 입력칸이 나타남
   - **관측정 자연수위** (m, 지표하). 기본값 = 자연수위.
   - **관측정 거리** (m). 빈 칸으로 시작, 모르면 비움.
3. **기준수위** = 관측이면 관측정 자연수위, 아니면 자연수위.
   - 수위 곡선의 **0분 수위 = 기준수위**
   - 강하 `s(t) = 수위(t) − 기준수위` (해석·그래프 모두 이 기준)
4. **자연수위(양수정)는 그대로 유지**하며 다음에 씀
   - 일보 머리말의 자연수위 칸
   - 가용강하 = 펌프 설치심도 − **자연수위** − 안전여유, 적정양수량 검토
5. **수질 입력 없음**: 관측이면 수온·pH·EC 입력칸을 숨기고 일보 수질 칸을 비움.
   자동 생성값도 넣지 않음.
6. 관측정 거리는 일보에 **기록만** 하고 계산에는 쓰지 않음.

## 2. 변곡점과 한계양수량 (비수위강하량도)

### 개념 (현업 설명 요약)
- 단계양수시험 목표: 단계별 Q를 올리며 sw/Q가 **급격히 꺾이는 변곡점**을 찾는 것.
- 추세선을 두 구간(1~k단계, k~N단계)으로 나눴을 때 **두 추세선의 교점 Q = 한계양수량**.
  적정취수량은 그 안에서 정합니다.
- 변곡점은 보통 2~3단계에 나타나고, 물이 풍부하면 4단계까지 없습니다.
  없으면 한계양수량은 **마지막 단계 양수량 이상**으로 봅니다.

### 2-1. 실측 단계 결과 → 한계양수량
원본 `core/hydrogeology.py` → `analyze_step_break()`

```js
// rates: 단계별 Q, sw: 단계별 최종강하. 반환 limitQ = 두 추세선 교점
function polyfit1(x, y) {                       // 최소제곱 직선 → [기울기, 절편]
  const n = x.length, mx = x.reduce((a, b) => a + b) / n, my = y.reduce((a, b) => a + b) / n;
  let sxy = 0, sxx = 0;
  for (let i = 0; i < n; i++) { sxy += (x[i] - mx) * (y[i] - my); sxx += (x[i] - mx) ** 2; }
  const a = sxy / sxx; return [a, my - a * mx];
}
function analyzeStepBreak(rates, sw, minRatio = 1.3) {
  const y = sw.map((s, i) => s / rates[i]), n = rates.length;
  let best = null;
  for (let k = 2; k < n; k++) {                 // k: 1-based 변곡 단계. 앞 1..k, 뒤 k..N (k 공유)
    const [a1, b1] = polyfit1(rates.slice(0, k), y.slice(0, k));
    const [a2, b2] = polyfit1(rates.slice(k - 1), y.slice(k - 1));
    if (a1 <= 0 || a2 <= a1) continue;
    if (!best || a2 / a1 > best.ratio) best = { ratio: a2 / a1, k, a1, b1, a2, b2 };
  }
  if (!best || best.ratio < minRatio) return { found: false, ratio: best ? best.ratio : 1 };
  const q = (best.b2 - best.b1) / (best.a1 - best.a2);
  return { found: true, k: best.k, limitQ: q, limitY: best.a1 * q + best.b1, ratio: best.ratio };
}
```
- 단계가 3개 미만이면 루프가 돌지 않아 `found:false`.
- `found:false`이면 "한계양수량 ≥ 마지막 단계 Q"로 표시.

### 2-2. 계획 단계에 변곡점 가정 넣기 (선택)
원본 `step_final_drawdowns()`. 마지막 단계 강하와 변곡점 단계로 단계별 강하를 만듭니다.
데스크톱은 이걸로 일보 곡선을 합성합니다. 모바일에서는
"변곡점이 2단계/3단계에 오면 예상 수위가 어떻게 되나"를 보여주는 데 쓸 수 있습니다.

```js
// sw/Q = B·g(Q), g = 1 + c·Q (Q ≤ Qb), 이후 기울기 breakRatio 배
function stepFinalDrawdowns(rates, lastDrawdown, breakStep, breakRatio = 3.0, aqFraction = 0.5) {
  const f = Math.min(Math.max(aqFraction, 0.05), 0.95);
  const c = (1 - f) / (f * rates[0]);
  const Qb = breakStep && breakStep >= 1 && breakStep < rates.length ? rates[breakStep - 1] : null;
  const g = q => (Qb === null || q <= Qb) ? 1 + c * q : (1 + c * Qb) + breakRatio * c * (q - Qb);
  const B = lastDrawdown / (rates.at(-1) * g(rates.at(-1)));
  return rates.map(q => q * B * g(q));
}
```
- 상수: `STEP_BREAK_RATIO = 3.0`, `STEP_AQ_FRACTION = 0.5` (1단계 sw/Q 중 대수층손실 B의 비율).
- `breakStep = null` → 꺾임 없는 순수 Jacob 직선.

## 3. 적정양수량 (다중 제약)
원본 `optimal_yield_jacob()`. 단계 결과의 Jacob `sw = B·Q + C·Q²`로 계산합니다.
- B, C: (Q, sw/Q) 직선회귀의 절편 B, 기울기 C

```js
function optimalYield({ B, C, pumpDepth, nat, margin = 0.5, factor = 0.7, hp, pipeMm,
                        vMax = 2.0, eff = 0.45, pipeHead = 5.0 }) {
  const sAvail = Math.max(pumpDepth - nat - margin, 0.1), sSafe = sAvail * factor;
  const solve = s => C > 0 ? (-B + Math.sqrt(B * B + 4 * C * s)) / (2 * C) : (B > 0 ? s / B : 0);
  const Qsafe = solve(sSafe), Qmax = solve(sAvail), Qwalton = C > 0 ? B / C : Infinity;
  const cand = { well: Qsafe };
  if (hp > 0) cand.pump = hp * 745.7 * eff / (1000 * 9.81 * (pumpDepth + sSafe + pipeHead)) * 86400;
  if (pipeMm > 0) cand.pipe = vMax * Math.PI * (pipeMm / 2000) ** 2 * 86400;
  const binding = Object.keys(cand).reduce((a, b) => cand[a] <= cand[b] ? a : b);
  return { sAvail, sSafe, Qsafe, Qmax, Qwalton, Qfinal: cand[binding], binding, ...cand };
}
```
- 우물효율(Q_safe 기준) = `B·Q / (B·Q + C·Q²) × 100`.
- 모바일의 기존 `R.qmax`(240분 연속 최대 양수량)는 다른 계산입니다.
  30분 직선 + 안전율로 구하므로 이걸로 대체하지 말고, 실측 단계 결과가 있을 때 **추가로** 보여주세요.
- 모바일에는 마력·토출관 입력이 없습니다. 추가하지 않으면 `hp`, `pipeMm`를 생략해 우물 제약만 쓰세요.

## 4. (선택) 단계 내 곡선 모양
원본 `design_pump_curve()`, `max_pump_slope()`.
각 단계 = 작은 연속시험: 로그시간 직선 주 구간 → 수위안정화(수평).
모바일 `drawCurve()`는 지금 Jacob 중첩이라 끝까지 내려갑니다.
현장 관행처럼 안정화되는 곡선을 그리고 싶을 때만 이식하세요.

```js
const KNEE_W = 0.08, STAB_TOL = 0.003;
const softplus = z => z > 30 ? z : Math.log1p(Math.exp(z));
function kneeX(stabMin, slope) {
  const a = STAB_TOL / Math.max(slope * KNEE_W, 1e-12);
  const z = a < 30 ? Math.log(Math.expm1(a)) : a;
  return Math.log10(Math.max(stabMin, 2)) + KNEE_W * Math.min(z, -1);
}
// t: 단계 내 경과분, final: 단계 증분강하, stabMin: 수위안정화 시작(분), slope: m/log주기
function pumpCurve(t, final, stabMin, slope) {
  if (t <= 0) return 0;
  const xs = kneeX(stabMin, slope), x = Math.log10(t);
  return Math.min(Math.max(final - slope * KNEE_W * softplus((xs - x) / KNEE_W), 0), final);
}
```
- 기울기 상한 `max_pump_slope`: 1분 강하가 최종의 5% 이상 남는 최대 기울기를 이분법으로 구합니다.
  데스크톱 자동값 = 상한 × 0.6.
- 단계 곡선은 단계 종료 시각에 정확히 증분이 되도록 `curve × (final / curve(end))`로 비례 보정합니다.
- 단계 내 표준 측정 시각: 0~5분 1분 간격, 이후 5분 간격, 종료 시각 포함.
